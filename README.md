# NGO Impact Measurement Dashboard

## Project Overview

This project analyzes NGO program performance, beneficiary engagement, and social impact using data analytics, SQL, and Power BI.

The dashboard helps stakeholders monitor key performance indicators (KPIs), evaluate program effectiveness, and support data-driven decision making.

---

## Objectives

- Track beneficiary participation
- Measure program completion rates
- Analyze employment outcomes
- Monitor improvement percentages
- Evaluate overall social impact

## Dashboard Pages

### Page 1 – Executive Summary
Provides an overview of beneficiaries, program costs, employment rate, and impact success rate.

### Page 2 – Program & Demographic Analysis
Analyzes beneficiaries by program, district, gender, and completion status.

### Page 3 – Impact & Trends
Tracks beneficiary growth, employment outcomes, and improvement trends over time.

### Page 4 – KPI Tree
Maps NGO activities to outputs, outcomes, and long-term impact.
